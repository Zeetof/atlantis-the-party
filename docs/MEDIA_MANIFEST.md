# Media manifest

All media derives from the organizer-supplied archive in `assets-source/`. Original files are preserved and are never overwritten. Outputs are generated by `npm run assets:prepare`; the private review item is copied only to `storage/private/`.

## Processing rules

- Flyers and promos are metadata-stripped, auto-rotated, resized to a maximum width of 1500px and encoded as WebP (quality 86).
- Video posters are resized to 720px wide and encoded as WebP (quality 82).
- Event highlight videos are copied byte-for-byte; they are not re-encoded or trimmed.
- The review-only clip and its poster are written to `storage/private/` and are **not** copied into `public/`.
- No stock imagery was introduced. No media was generated with image tools.

Regenerate everything after changing the source archive:

```bash
npm run assets:prepare
```

## Usage constraints

- Do not add copyrighted Juice WRLD album art, lyrics, photographs or audio. The tribute card artwork in `src/components/tribute/` is original SVG.
- Do not add aquatic/water imagery; the brand is editorial black, crimson and chrome.
- Do not relabel 2.0 or 3.0 assets as Atlantis 4.0.
- Do not publish the held clip without written organizer approval and confirmed consent.
- Keep the original archive intact; only generated copies belong in `public/media`.
